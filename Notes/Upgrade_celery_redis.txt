Why we added this
Email sending was a blocking operation — Flask waited for the email to send before responding to the user.
Celery + Redis makes it a background task — Flask responds instantly and email sends behind the scenes.

1. User submits email form
2. Flask receives it → calls send_email_task.delay()
3. Task gets dropped into Redis queue instantly
4. Flask redirects user back to page immediately
5. Meanwhile Celery worker picks up the task from Redis
6. Celery sends the email in background
7. User has no idea any of this happened — page just loaded instantly
