Features

What it does

Live Weather Lookup

Fetches real-time weather data from OpenWeatherMap for any city, including forecasts for future travel dates.

AI Chat Interface

Conversational UI powered by Groq's Llama 3.3 70B model. Asks follow-up questions when weather is bad — indoor or outdoor plans?

Email Delivery

Packing lists sent via Gmail SMTP as a background task. Celery + Redis handle the queue so the user doesn't wait.

JWT Authentication

Secure login and registration with hashed passwords and JWT tokens stored in HTTP-only cookies.
